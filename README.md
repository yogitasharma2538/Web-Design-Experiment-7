# Experiment 7: Notes App using React.js

## Aim
To develop a Single Page Application (SPA) using React.js that allows users to create, view, update, and delete notes.

## Description
This project is a simple and responsive Notes App developed using React.js. It provides an interface where users can manage their notes easily. The application uses React components and hooks to manage data and update the user interface dynamically.

## Features
- Add new notes
- View existing notes
- Edit notes
- Delete notes
- Search notes
- Automatically save notes in browser storage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React.js
- React Hooks (useState, useEffect, useMemo)
- Local Storage

## Files Included
- `index.html` – Contains the HTML structure and React application.
- `style.css` – Contains styling and responsive design.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Start adding, editing, searching, and deleting notes.

## Outcome
Successfully developed a React-based Notes App with CRUD operations and browser storage functionality.
